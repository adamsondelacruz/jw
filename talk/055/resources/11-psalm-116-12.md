# Psalm 116:12

WOL: <https://wol.jw.org/en/wol/b/r1/lp-e/nwtsty/19/116#v=19:116:12>

## Outline Use

Supports the point that love and gratitude, not mere obligation, motivate us to please Jehovah.

## Key Thought

When we notice Jehovah's goodness, we naturally ask how we can respond.

## REIA Prep

- Read: Optional supporting text.
- Explain: Gratitude changes obedience from duty into willing response.
- Illustrate: A flower turns toward the sun because it receives warmth and light.
- Apply: Invite listeners to think of one specific way Jehovah has shown goodness to them.
